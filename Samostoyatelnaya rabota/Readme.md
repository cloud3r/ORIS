Самостоятельная работа

http://localhost:8080/

1\.	GET http://localhost:8080/websites — вывести список сайтов с фильтрацией по типу type.

2\.	GET http://localhost:8080/websites/details?id=1 — получить подробную информацию о сайте.

3\.	POST http://localhost:8080/websites/create — добавить сайт с полями name, url и type.

4\.	PUT http://localhost:8080/websites/update?id=1 — изменить название, адрес, тип и статус проверки.



3 и 4 делается в Postman \[POST/PUT]URL -> Body -> raw -> текст в виде json
